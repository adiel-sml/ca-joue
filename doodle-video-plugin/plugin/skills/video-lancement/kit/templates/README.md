# Modèles de formats

Choisis le modèle qui sert le sujet, copie son story.json et son lines.json, puis écris les répliques. La structure est un point de départ : chaque vidéo garde son histoire.

- [`top5`](top5.md) : Top 5 (ou top 3). Classer des éléments : 5 astuces, 5 erreurs, 5 lieux, 5 fonctions d'une appli.
- [`avant-apres`](avant-apres.md) : Avant / après. Montrer une transformation : sans l'appli puis avec, avant le conseil puis après.
- [`mythe-realite`](mythe-realite.md) : Mythe ou réalité. Démonter des idées reçues, une par une, avec un fait vrai et sourcé.
- [`tuto-3-etapes`](tuto-3-etapes.md) : Tuto en 3 étapes. Apprendre à faire quelque chose : une recette, un réglage, une démarche.
- [`sketch`](sketch.md) : Sketch dialogué. Une situation drôle entre deux ou trois personnages, avec une chute.
- [`temoignage`](temoignage.md) : Témoignage. Une personne raconte ce qui lui est arrivé, en vrai ou en exemple.
- [`erreurs`](erreurs.md) : 3 erreurs à éviter. Prévenir : les erreurs fréquentes et ce qu'il faut faire à la place.
